# data/

Everything here is generated by executing code in this repository.

| File | Generator | Content |
|---|---|---|
| `phase1_fault_matrix.md` | `tools/phase1_report.py` | Outcome of every (decapsulation rule, fault, ciphertext case) in the toy KEM, and the coordinate-0 attack result |
| `phase2_benchmarks.json`, `.md` | `tools/run_benchmarks.py` | Classification counts, class counts at levels L1–L4, bounds and timings per circuit |
| `certificates/*.json` | `tools/fault_site_manifest.py` | Program, every certificate, site manifest and checker report for one circuit |
| `transcripts/pytest_2026-11-11.txt` | `python -m pytest -v` | Full test transcript (139 passed) |

Timings are wall-clock on the machine recorded in `phase2_benchmarks.json`
and will differ elsewhere. Counts are deterministic (analyzer seed 0).

Third-party material is not stored here. The DFAR replication package was
inspected outside the repository; its identifiers are in
`reports/phase0_prior_art.md`.
